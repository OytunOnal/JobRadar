## Main-session audit, 2026-09-04

This file is the deep pass's output; every headline number in it was
re-fetched here and agreed. karriere.at's robots.txt names only BLEXBot and
AhrefsBot, with an empty `Disallow:` under the wildcard group — no AI-crawler
ban. The declared sitemap
`https://www.karriere.at/static/sitemaps/sitemap-jobs-https.xml` holds
**12,749** `<loc>` entries, and a sampled detail page carries complete
`JobPosting` JSON-LD (title, hiringOrganization, addressLocality, datePosted,
and a 6,794-character description).

**The path is the finding.** A screening pass reported this same board on
`https://www.karriere.at/sitemap-jobs-https.xml`, which answers **404** with a
70KB HTML error page. The working URL is the one robots.txt declares, under
`/static/sitemaps/`. Same board, same hour: shut at the guessed path, wide
open at the declared one. Every subsequent country pass reads robots.txt in
full and follows its `Sitemap:` lines rather than guessing `/sitemap.xml`,
and this is why.

Adapter shipped as `src/lib/sources/karriereat.ts`. Note that Austria is not
in `JUDGE_TARGETS`, so these postings enter the pool and wait on that
decision rather than reaching the judge — a one-word change when the user
wants it.
