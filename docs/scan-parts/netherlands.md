# Netherlands source scan

Scope: Dutch-market job sources for a candidate needing **visa sponsorship**
(kennismigrant / highly skilled migrant). Scanned 2026-09-02. Every yes/no below
was decided by fetching the URL in the row, not by reading a marketing page.
Sources already in the registry (EURES, Arbeitnow, Adzuna, JSearch, LinkedIn,
the 30 ATS adapters, …) are out of scope and are only named where a Dutch board
turned out to be a re-skin of one.

## Checked, not worth it

- **Expatica jobs** — not a board. `https://www.expatica.com/nl/jobs/` renders listings that link straight out to `adzuna.nl/land/ad/...` and `nl-affiliate-apply.jooble.org`. **Already covered via Adzuna**; the Jooble half adds nothing we can attribute.
- **Together Abroad** — `https://www.togetherabroad.nl/jobs` is server-rendered, but the postings are a StepStone **Germany** affiliate feed (`stepstone.de/stellenangebote--…-inline.html?&cid=partner_togetherabroad___SP`). Dutch expat branding, German inventory. Skip.
- **indsponsors.nl** — advertises a searchable directory of 12,000+ IND sponsors plus a jobs page; `robots.txt` explicitly welcomes ClaudeBot, but `https://indsponsors.nl/jobs` and `https://indsponsors.nl/directory` both return the **same 6,027-byte SPA shell** with no server-rendered content, and the sitemap holds only 44 static URLs. It is also downstream of the IND register we can read directly. Skip.
- **IamExpat RSS** — `https://www.iamexpat.nl/rss-feeds` offers only news feeds (`/rss/news-netherlands`, `/rss/news-netherlands/news`); there is no jobs feed. Use the paginated listing instead. Note that IamExpat's `robots.txt` disallows `/job/`, `/jobProvider/`, `/jobs-iframe/` and `/search/` — the `/career/jobs-netherlands…` paths we would actually use are *not* disallowed, and `Crawl-delay: 1` applies.
- **IamExpat sitemap for enumeration** — `https://www.iamexpat.nl/sitemap.xml?page=1` holds 91 `career/jobs-netherlands` URLs, but they are category and city landing pages (`/providers`, `/amsterdam`), not postings. Enumeration has to come from `?page=N`.
- **IND register, Dutch URL** — `https://ind.nl/nl/openbaar-register-erkende-referenten/openbaar-register-regulier-arbeid` returns **404**. Use the English path in the table. No CSV/XLSX export is offered anywhere on the register pages; the HTML table is the download.

## Note on the IND register

It is the one item here that is not a job board and is worth more than any of
them. The register is the statutory list of employers permitted to sponsor a
highly skilled migrant, refreshed monthly, served as plain HTML with a KVK
number per row — a clean join key. Matched against postings we already ingest
(and against the ATS tenants already discovered), it converts "does this company
sponsor?" from an LLM guess into a lookup. Everything else in this scan is a
marginal volume gain; this is a precision gain on the user's actual constraint.
